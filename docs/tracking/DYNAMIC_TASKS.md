# RepoPilot Dynamic Tasks

This file tracks implementation work discovered after the 2,315-task baseline was locked.

## ID Format

`RPD-xxxx`

## Rules

1. A dynamic task must represent newly discovered implementation work that is not already covered by an existing baseline task.
2. Dynamic tasks never replace or renumber existing baseline tasks.
3. Every dynamic task records the discovery reason and the baseline task or batch that exposed it.
4. Dynamic tasks must have explicit acceptance criteria before implementation.
