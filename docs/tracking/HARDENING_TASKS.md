# RepoPilot Hardening Tasks

This file tracks security, resilience, performance, operational, and production-hardening work discovered during implementation.

## ID Format

`RPH-xxxx`

## Rules

1. Hardening work must state the risk or weakness being addressed.
2. Hardening work must not silently replace functional baseline tasks.
3. Security-sensitive hardening takes precedence when continuing without it would make later work unsafe.
4. Completed hardening work must include verification evidence.
