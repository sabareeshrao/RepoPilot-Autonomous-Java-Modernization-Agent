# RepoPilot Bug Tasks

This file tracks defects discovered during implementation, testing, integration, or repository verification.

## ID Format

`RPB-xxxx`

## Rules

1. Each bug task records the observed behavior.
2. Each bug task records the expected behavior.
3. Each bug task records the task or batch that exposed the defect.
4. A bug task is complete only after the fix is verified.
